Menu-Bar Screenshot & Annotation Tool for macOS

Capture screen regions, annotate with vectors & text, run Apple Vision OCR, and copy/save instantly — all from your Mac's menu bar.

⬇ Download Universal .ZIP (635 KB) ⚡ Build from Source
🎯

Multiple Capture Modes

Support for Area Region selection, Fullscreen, Active Window highlight, Last Region re-capture, and Scrolling Stitching.

🎨

Annotation Canvas

Draw arrows, text, auto-incrementing step markers (1, 2, 3...), rectangles, freehand pencil, crop canvas, and pixelate blur/mosaic.

🔠

Vision OCR & Search

Instantly extract text from screenshots using Apple's Vision Framework (English, Vietnamese, Japanese) and search capture history by text.

⌨️

Global Hotkey Recorder

Rebindable global shortcuts using Carbon API. Trigger capture modes instantly from anywhere in macOS.

📌

Pin to Screen

Pin annotated screenshots floating on top of all windows for easy reference during research or coding.

💻

Universal 2 Binary

Native 60fps performance on both Apple Silicon (M1/M2/M3/M4) and Intel Macs with zero third-party dependencies.
