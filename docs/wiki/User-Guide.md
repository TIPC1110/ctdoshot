# User Guide

## Default Hotkeys

| Action | Shortcut |
|---|---|
| Capture Area | `⇧⌘S` |
| Capture Screen | `⇧⌘3` |
| Capture Active Window | `⇧⌘W` |
| Capture Last Region | `⇧⌘L` |
| Scrolling Capture | `⌥⇧⌘X` |
| Quick OCR (Region to Clipboard) | `⌃⌥⌘O` |
| History Gallery | `⇧⌘H` |

## Annotation Editor Tools

- **Select:** Mode indicator.
- **Arrow (`⇧⌘A`):** Draw directional arrows.
- **Text:** Insert custom text annotations.
- **Step Counter:** Auto-incrementing step markers (1, 2, 3...).
- **Rectangle:** Highlight rectangular areas.
- **Pencil:** Freehand drawing.
- **Crop:** Crop canvas to selected area.
- **Blur / Mosaic:** Pixelate sensitive information.
- **Copy (`⌘C`):** Copy annotated image to clipboard.
- **Save (`⌘S`):** Save file and copy file path.
