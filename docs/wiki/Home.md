## 🌟 Overview

**ctdoshot** is a modern, lightweight menu-bar screenshot application built natively for macOS 13+ in Swift 5.9.

### Key Features
- 📸 **Capture Modes:** Area region selection, full screen, active window, last region, scrolling capture.
- 🎨 **Annotation Editor:** Arrows, text, step numbers (1, 2, 3...), rectangles, freehand pencil, crop, pixelate blur/mosaic.
- 🔠 **OCR Text Recognition:** Vision framework (English, Vietnamese, Japanese) with history search.
- ⌨️ **Global Hotkeys:** Fully customizable shortcut chords (Carbon API).
- 📌 **Pin to Screen:** Pin captured screenshots floating on top of all windows.
- 💻 **Universal 2 Support:** Native performance on both **Apple Silicon (M1–M4)** and **Intel Macs**.
- 🌐 **i18n:** English + Tiếng Việt interface strings and localized tooltips.
